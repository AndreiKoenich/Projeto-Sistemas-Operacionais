Este projeto foi desenvolvido na disciplina de Sistemas Operacionais II da Universidade Federal do Rio Grande do Sul.
O objetivo é colocar em prática os conceitos de comunicação e sincronização de processos, abordados em aula.
Para mais informações, consulte o arquivo "Descrição.pdf".
Para compilar e executar o programa em Linux, basta utilizar o comando "make", seguido dos comandos "./myServer" e "./myClient" para
executar as aplicações servidor e cliente, respectivamente.
